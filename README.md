# Mahmoud Maher — Portfolio

Personal portfolio website for **Mahmoud Maher**, Software Testing Engineer & QC/QA Specialist.

🌐 **Live Site**: [mahmoud-maher-portfolio.vercel.app](https://mahmoud-maher-portfolio.vercel.app)

---

## About

A modern, responsive portfolio showcasing:
- Technical summaries & study resources (ISTQB, Mobile, Embedded, College)
- Projects & certificates
- Contact & social links

---

## Tech Stack

- **React** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **shadcn/ui** (components)

---

## Getting Started

```sh
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

---

## Deployment

Deployed via **Vercel** with automatic deployments on every push to `main`.
